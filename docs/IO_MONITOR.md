# 实时 IO 看板（2026-10-30）

入口：主页「实时 IO 日志」或游戏页「实时 IO 日志 · GPIO 8–13」。

| GPIO | 部位 | 功能 |
| --- | --- | --- |
| 8 | 头部 | 互动语音 |
| 9 | 左脸颊 | 互动语音 |
| 10 | 右脸颊 | 互动语音 |
| 11 | 肚子 | 互动语音 |
| 12 | 游戏 ↑ | 原有游戏控制 |
| 13 | 游戏 ↓ | 原有游戏控制 |

游戏连接栏统一显示六路指示：● 触摸、○ 松开、— 暂无数据。独立看板显示触发次数、上次触发时间、按住时长、原始值、基准值、触发阈值、触摸和松开日志，以及固件报告的语音入队或忙碌跳过原因。

## 连接与兼容性

- USB：网页点击连接，选择 CH343（COM5 或电脑当前分配的端口），115200 波特率。先松开所有铜箔，再依次触摸。
- 与游戏共用同一个连接，切换网站内页面不重复连接。不要同时打开 Arduino 串口监视器。
- 已有固件的 USB `bodyMask` 可提供 GPIO8–11 状态，`left/right` 提供 GPIO12/13。GPIO8/9 原始数值以前未上报，因此旧固件会显示「—」，不影响已上报的触摸状态。
- 本次仅在固件源码补充 `raw8/baseline8/press8` 和 `raw9/baseline9/press9`；后续重新编译、烧录后这两路数值才会显示。本次没有烧录，也未改变阈值、音频或游戏逻辑。
- 当前蓝牙及 Wi-Fi 协议仅提供 GPIO12/13。GPIO8–11 不会伪装成松开状态；完整六路监测请使用 USB。本次没有修改或部署无线协议。
- 信号失效、断开或校准期间状态显示未知。初次连接时已按住的输入记为状态同步，先观察到松开再计数，避免把重连误算为新触摸。

## 日志

记录在当前账号会话内存中，保留最近 1,000 条事件、600 帧采样；切换网站内页面会继续收集，刷新、关闭页面或切换账号会清空。切到其他页面期间仍须保持连接和浏览器运行，系统休眠会中断记录。

「暂停滚动」只冻结日志视图，实时状态及后台记录继续；可筛选某个 IO，清空记录，导出 CSV 事件或 JSON（事件及采样）。只保留白名单中的传感器／队列字段，不收集对话、音频、配对码或任意串口文本。传感器数据不自动上传数据库。

「语音已入队」仅代表固件接受播放任务，不代表扬声器已实际发声。忙碌跳过不等于铜箔未触发。原始值是电容触摸采样，不是压力测量。
